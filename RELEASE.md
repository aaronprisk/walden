# Release notes - Walden 1.0.4
2026-08-26

## Major Changes

* **Local Audio File Support**

A new custom button for adding local audio files (.mp3 & .wav) to blog posts has been added to the EasyMDE editor. Walden will stage, upload and wrap audio file within html audio tags so it can be rendered within typical static site generators. 

* **Improved Preview**

Post preview system has been improved and can now properly display staged assets including local images and audio files.

* **General Bug Fixes**

Multiple bugs and issues were addressed to improve overall stability and performance.
